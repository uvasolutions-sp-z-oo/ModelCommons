# @modelcommons/embedded

Optional in-process composition of the ModelCommons client, model store,
device profiles and llama.rn runtime. The application supplies the store
and owns the runtime process and the model lease lifecycle.

Use the [nine-archive local install](https://github.com/uvasolutions-sp-z-oo/ModelCommons/blob/HEAD/docs/getting-started.md#build-packages-for-your-own-client).
The mobile integration uses the reviewed `llama.rn@0.12.9` pin. See the
[reference client](https://github.com/uvasolutions-sp-z-oo/ModelCommons/tree/HEAD/examples/reference-client)
and the included MIT license. Physical-device coverage is recorded in the
[device verification notes](https://github.com/uvasolutions-sp-z-oo/ModelCommons/blob/HEAD/docs/verification/physical-devices.md).
